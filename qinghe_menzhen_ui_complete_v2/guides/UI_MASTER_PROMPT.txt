【AI 医生机器人】
圆润机器人头部，深蓝显示屏脸，青绿色/浅蓝色外壳，白色医生服，小型听诊器，医疗卡片，友善微笑。
旁边少量叶片、心形、医疗十字。
扁平矢量，premium，transparent background。
不要写实人物、不要 3D、不要文字、水印。

【输入区域】
标题：症状描述
textarea placeholder：
例如：喉咙痛，低烧两天（回车发送，Shift+回车换行）
右下角：麦克风、图片
右侧：联网补充 Toggle
主按钮：发送
次按钮：先给分析

【图标】
全部使用统一 SVG / Lucide 风格。
stroke 2.5~3.5px、round cap、round join。
禁止 Emoji、3D icon、写实 icon。
优先使用 icons_svg 中的 SVG。

【响应式】
>1100px：完整 Sidebar。
800~1100px：Sidebar 约 280px。
<800px：Sidebar 抽屉式，主区域占满。

【医疗产品原则】
不要制造确定性诊断或治疗保证。
不要加入广告、商城、会员充值、游戏化、无关 Banner。
视觉重点始终是：AI 对话、症状输入、发送按钮。
