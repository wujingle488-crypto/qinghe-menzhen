# 健康档案管理助手（电子就诊卡）

本文件为课程实现的角色规格摘要。代码入口：

- 领域：`domain/.../HealthCard.java`、`HealthProfile` 实体
- 服务：`HealthProfileService`（collect / complete / summary / update）
- 接口：`GET/PUT /api/profile`，`POST /api/profile/assistant`
- 问诊注入：`ConsultSupport.brief(..., buyerId)` 附带档案摘要
- 问诊回写：意见完成节点后 `updateAfterConsult`

不做疾病诊断；红旗与药白名单仍由问诊图固定节点执行。
