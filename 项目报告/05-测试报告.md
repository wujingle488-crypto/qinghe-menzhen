# 第 5 章 测试报告

## 5.1 测试目的与范围

验证青禾门诊系统在**正常路径、安全路径、异常路径、非合理输入**下行为符合需求，支撑课堂验收。

| 范围 | 是否覆盖 |
| --- | --- |
| 领域门禁与摄入逻辑 | 是（单元测试） |
| 问诊主流程与知识目录 | 是（集成/流程测试） |
| 就诊卡多卡 | 是（单元测试） |
| 前端交互与多媒体 | 是（手工验收） |
| 性能压测 / 安全渗透 | 否（课程范围外，仅说明） |

## 5.3 测试策略

1. **单元测试**：门禁、红旗否定、就诊卡、检索融合、记忆等纯逻辑。  
2. **流程 / 集成测试**：真实 Spring 上下文下走问诊关键路径。  
3. **手工场景测试**：对照演示剧本与 UI 交互。  
4. **回归测试**：针对已记录 Bug-01～03 复测。  

自动化执行示例：

```bash
mvn -pl domain,agent-server -am test
```

## 5.6 Bug 发现与复现

本轮按“当前版本可稳定复现、实际结果明确偏离预期”的标准重新筛选 Bug。已修复的过期会话、多卡唯一索引不再作为当前 Bug 汇报。

| Bug | 激活条件摘要 | 实际结果 | 严重度 | 重复结果 |
| --- | --- | --- | --- | --- |
| Bug-01 阅读中搜索失效 | 打开文章后在左侧搜索框输入“流感” | 搜索词改变，但页面仍停留在原文 | 中 | 3/3 |
| Bug-02 感冒文章分类错误 | 直接打开知识库“用药指南” | 《普通感冒和流感不要混为一谈》被归入用药指南 | 中 | 3/3 |
| Bug-03 新会话就诊卡关联失效 | 首条消息前选择就诊卡，再发送“我叫什么名字？” | 页面显示已关联，后端仍为未关联，回复未使用卡片 | 高 | 3/3 |

完整激活条件、复现步骤与截图见仓库根目录 `Bug记录.md` 和 `项目报告/BUG证据/`。

## 5.7 测试结论

1. 三个当前 Bug 都来自正常点击或正常提问，不依赖故意输入非法数值。  
2. 三个 Bug 均已记录激活条件、预期/实际结果、截图并重复验证 3 次。  
3. 普通页面可以打开；搜索状态、知识分类和新会话关联仍存在程序错误。  
4. Bug 汇报应优先现场演示 Bug-01，并用截图说明 Bug-02、Bug-03。
