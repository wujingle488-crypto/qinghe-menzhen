# 第 4 章 系统实现

## 4.1 工程结构

```text
commerce-cs-agent/
├── domain/                 # 领域模型、门禁、主数据、部分单测
├── agent-server/           # Spring Boot 应用、编排、REST/SSE、集成测试
├── web/                    # React + Vite 前端
├── data/                   # 上传文件与本地数据
├── docs/                   # 模块说明
└── pom.xml                 # Maven 多模块父工程
```

前端通过 Vite 代理 `/cs-api` → `http://127.0.0.1:8082`。

## 4.2 已实现功能清单（体现系统体量）

| 子系统 | 已实现要点 |
| --- | --- |
| 智能问诊 | 会话生命周期、多轮对话、SSE 流式、结构化建议卡片、中断恢复 |
| 安全门禁 | 红旗拦截、否定语解除、药品白名单 |

| 历史管理 | 列表、打开、重命名、删除、多选批量删除、可滚动侧栏 |
| 多媒体 | 图片观察、语音转写 |
| 知识库页 | 浏览、检索、运营补录 |
| UI 体系 | 青禾品牌视觉、桌面/移动侧栏、欢迎引导 |

上述能力组合表明本项目为**可运行软件系统**，而非单一算法小程序。

## 4.3 关键实现说明

### 4.3.1 后端启动与配置

- 入口：`CsApplication`  
- 端口：`8082`  
- 数据源：MySQL 库 `commerce_cs`  
- LLM / RAG 开关见 `application.yml`（`llm.*`、`rag.*`）  

启动命令示例：

```bash
# 后端
java -jar agent-server/target/agent-server-1.0.0.jar

# 前端
cd web && npm run dev
```

### 4.3.2 问诊发送（前端要点）

1. 确保存在有效 `sessionId`（否则 POST 新建）。  
2. 组装 `text`、`webSearch`、`imageIds`。  
3. 以 SSE 读取 `retrieving` / `generating` / `result`。  
4. 错误正文优先解析 `{error}`，避免把 JSON 当聊天气泡。  
5. 若提示会话不存在：清理本地键并自动重试一轮。  

### 4.3.3 历史三点菜单（前端要点）

- 组件：`HistorySideList`  
- `···` 菜单：重命名（行内编辑）、多选、删除  
- 菜单使用 `fixed` + Portal，避免被侧栏滚动裁切  
- 列表固定行高 + `overflow-y: auto`，避免条目被压扁  

### 4.3.4 门禁与就诊卡（后端要点）

- `SafetyGate`：危急识别与否定解除  
- `HealthProfileSchemaFix`：清除历史 `user_id` 唯一索引，支持多卡  
- `ConsultHistoryService.rename/deleteMany`：标题与批量删除  

## 4.4 演示环境搭建步骤（摘要）

1. 启动 MySQL，确保库与账号可用。  
2. 打包并启动 `agent-server`。  
3. 安装前端依赖后 `npm run dev`。  
4. 浏览器打开 `http://localhost:5173/`。  
5. 按附录剧本走通上感 / 过敏 / 红旗三条路径。
